# alignment/40_percent/

**Final split used for all thesis results.** GraphPart at a 40% identity threshold (`--test-ratio 0.1 --val-ratio 0.05`).

## Files

- `40pct_train.fasta` — 1,515 training sequences.
- `40pct_valid.fasta` — 88 validation sequences.
- `40pct_test.fasta` — 176 test sequences (58 positive, 118 negative).

These correspond exactly to the split recorded in `../../../../data/final_dataset_40.csv` and `../../graphpart_assignments_40.csv`.
