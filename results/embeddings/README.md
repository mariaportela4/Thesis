# results/embeddings/

Protein language model embeddings for the full dataset, generated by `../../src/embedding/generate_embedding.py`.

## Files

- `esm_embeddings.npy` / `esm_metadata.csv` — ESM-2 650M embeddings (1280 dimensions) and matching metadata, in the same row order.
- `bert_embeddings.npy` / `bert_metadata.csv` — ProtBERT embeddings (1024 dimensions).
- `prott5_embeddings.npy` / `prott5_metadata.csv` — ProtT5-XL-U50 encoder embeddings (1024 dimensions).

Only the metadata CSVs are tracked in git; the `.npy` arrays are regenerated by the pipeline.

## Subfolders

- `split/` — the same embeddings, partitioned into train/val/test.

## Notes

- Each sequence is embedded independently and its last hidden state reduced to one vector by attention-mask-weighted mean pooling, with a 1024-token cap. No `[CLS]` token is used.
- Sequences are read from `../../data/merged_input_normalized.fasta`, keyed by `orig_id`; the dataset CSV supplies IDs and labels only.
- These must be regenerated whenever the dataset changes. Misaligned rows between embeddings and labels are a silent failure mode — they produce near-perfect but meaningless metrics — so row order is verified by identifier matching before training.
