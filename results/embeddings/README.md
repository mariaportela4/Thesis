# results/embeddings/

Protein language model embeddings for the full dataset, generated by `../../embedding/generate_embedding.py`.

## Files

- `esm_embeddings.npy` / `esm_metadata.csv` — ESM-2 650M embeddings and matching metadata (row order must align).
- `bert_embeddings.npy` / `bert_metadata.csv` — ProtBERT embeddings and matching metadata.
- `prott5_embeddings.npy` / `prott5_metadata.csv` — ProtT5-XL embeddings and matching metadata.

## Subfolders

- `split/` — the same embeddings, partitioned into train/val/test according to the GraphPart 40% split.

## Notes

- These embeddings must be regenerated whenever `../../data/final_dataset_40.csv` changes. Misaligned rows between embeddings and labels are a silent failure mode (they produce near-perfect but meaningless validation metrics) — always verify alignment before training.
