# data/

Raw and processed sequence data for the DPO classifier, from initial collection through to the CD-HIT/GraphPart-ready merged input.

## Files

- `remove_duplicates.py` — deduplication script; first step of the pipeline (removes duplicate sequences from the merged positive/negative set).
- `merged_input.fasta` — combined positive + negative sequences after class balancing (1:2 ratio), used as CD-HIT input.
- `merged_metadata.csv` — metadata (labels, source, etc.) matching `merged_input.fasta`.
- `protein_domains.csv` — domain annotations used to build/validate the positive set (see `positive/` domain FASTA files).
- `final_dataset_40.csv` — **canonical reference file**: final sequence list + labels + train/val/test split assignment from GraphPart at 40% identity. This is the file all downstream scripts (embeddings, benchmarking) align against.
- `final_dataset_60.csv` — equivalent reference file for the 60% GraphPart run. Exploratory/comparison only — **not used for the final thesis results**.
- `test_sequences_clean.fasta` — current test-split FASTA, generated by `../src/make_train_fasta.py --dataset-csv final_dataset_40.csv --split test`, aligned to the GraphPart 40% split.
- `train_sequences_clean.fasta` — current train-split FASTA, generated the same way (`../src/make_train_fasta.py --split train`).

## Subfolders

- `positive/` — positive (DPO) sequence collection, by domain
- `negative/` — negative (non-DPO) sequence collection, deduplication and balancing steps
