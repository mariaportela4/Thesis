# src/datasets/

Data-fetching utilities used to build the initial sequence collection.

## Files

- `ncbi_fetch.py` — fetches the **negative** sequence set from NCBI RefSeq via Biopython's `Entrez` interface. Queries viral proteins (taxid 2731619), 400–1250 aa, then excludes anything with depolymerase-related keywords in the title (lyase, pectinase, glycanase, hyaluronidase, etc.) or hits on known depolymerase-associated conserved domains (pfam12708, cd20481, pfam12219, cl22684, pfam12217, pfam13472). Capped at 30,000 sequences, retrieved in batches of 400 via NCBI's history/WebEnv mechanism. Outputs `../../data/negative/negative_ids.txt` (UID list) and `../../data/negative/negative.faa` (FASTA), which then feed into the dedup step (`../../data/remove_duplicates.py`).

Not used for the positive set — the positive domain-based collection (`../../data/positive/domain_*.fasta`) is built separately. The individual `domain_*.fasta` files were manually exported per conserved domain (not generated by a script). The merging of these files into `../../data/positive/all_DPO_candidates.fasta` is done in `../../notebooks/01_domain_analysis.ipynb` — see `../../notebooks/README.md`.
