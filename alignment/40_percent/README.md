# alignment/40_percent/

**Final split used for all thesis results.** Output of GraphPart at 40% identity threshold (`--test-ratio 0.1 --val-ratio 0.05`), run via command line.

## Files

- `40pct_train.fasta` — training set sequences.
- `40pct_valid.fasta` — validation set sequences.
- `40pct_test.fasta` — test set sequences (178 sequences — see benchmark results in `../../results/`).

These correspond exactly to the split assignment recorded in `../../data/final_dataset_40.csv` and `../../results/graphpart/graphpart_assignments_40.csv`.
